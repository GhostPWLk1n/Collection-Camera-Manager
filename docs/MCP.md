# Проверка аддона через Blender MCP

Blender MCP подключается к запущенному Blender и выполняет команды Python через `bpy`. Аддон устанавливается и работает самостоятельно. Правила ниже применяются в Codex и Claude Code с доступным подключением к Blender.

## Подготовка

1. В начале сеанса вызови `get_addon_status` и `get_scene_info` или соответствующие инструменты своего сервера. Уточни версию Blender, открытый файл, активную камеру сцены, активный объект и View Layer. Если инструмент принимает `user_prompt`, передавай исходную формулировку пользователя.
2. Для действий, меняющих данные, используй отдельный процесс Blender с тестовой сценой или заведомо тестовую копию файла. Подтверди целевой сеанс по имени файла и данным сцены перед установкой, перезагрузкой или выполнением операторов. В рабочей сцене ограничься чтением, пока пользователь явно не запросит изменения. Сохраняй тестовые файлы только по отдельным путям.
3. Установи или загрузи `Collection_Camera_Manager.py` из проверяемой ветки. При программной перезагрузке сначала сними регистрацию предыдущего экземпляра, затем зарегистрируй новую версию. Перед запуском зафиксируй версию Blender, путь к модулю и SHA исходника.

## Сценарий проверки

1. Создай две камеры с отдельными блоками данных, вложенную коллекцию и тестовые объекты. Сделай первую камеру активным **объектом** в нужном View Layer. Панели и операторы читают `context.object`.
2. Вызови `bpy.ops.cam.save_collection_state()`. Проверь, что на данных первой камеры появился элемент `coll_states`, а его JSON содержит `collections` и `objects`.
3. Измени видимость объектов и коллекций и вызови `bpy.ops.cam.load_collection_state(index=0)`. Проверь отдельно `LayerCollection.exclude`, `Collection.hide_viewport`, `Collection.hide_render`, `Object.hide_viewport` и `Object.hide_render`. При нескольких слоях проверь Exclude в целевом слое и учитывай, что остальные перечисленные флаги относятся к общим данным.
4. Проверь обновление `cam.update_state_from_current`, экспорт `cam.export_collection_state` в текстовый блок и удаление `cam.delete_collection_state`. Проверь, что на второй камере с отдельными данными наборы не появились. При проверке сохранения открой заново тестовый `.blend` с оставленным набором.
5. Для правок UI проверь обе панели с выбранной камерой и их скрытие при выборе другого типа объекта. Если MCP предоставляет `look`, используй его для осмотра сцены. Наличие панелей и кнопок проверь в интерфейсе Blender.

Передавай в `execute_blender_code` небольшие блоки и выводи результаты проверок. Используй `bpy.context.temp_override` там, где оператору требуется конкретный контекст окна или области. Если MCP недоступен или подключён к рабочему файлу, выполни возможные проверки в отдельном Blender с тестовыми данными и укажи, что осталось непроверенным.
