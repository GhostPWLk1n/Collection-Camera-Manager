# Правила разработки Camera Collection State Switcher

Эти правила действуют для Codex и Claude Code. Исходник аддона находится в `Collection_Camera_Manager.py`, сценарий проверки через Blender MCP — в [docs/MCP.md](docs/MCP.md).

## Задачи и передача работы

- Перед началом проверь `git status --short --branch`, адрес `origin` и выполни `git fetch origin`. Прочитай актуальный Issue, PR и изменения относительно `origin/main`.
- Для задачи используй отдельную ветку от актуальной `origin/main`. При параллельной работе согласуй владельцев задачи и файлов и используй отдельные worktree или клоны. Если оба исполнителя меняют один и тот же файл аддона, выполняй их задачи последовательно.
- При передаче через GitHub по умолчанию Claude Code реализует задачу, запускает первичные проверки и открывает PR со ссылкой на Issue. Codex уточняет критерии приёмки в Issue, проверяет опубликованный diff и сценарии в Blender, фиксирует замечания в PR и после устранения блокирующих замечаний ведёт слияние. Назначение пользователя имеет приоритет.
- При передаче укажи номер Issue или PR, ветку, опубликованный SHA, изменённые файлы, результаты проверок с версией Blender и оставшиеся шаги. Ревью проводится для последнего SHA. Публикуй проверенные коммиты обычным push и сверяй SHA удалённой ветки.
- Сохраняй незакоммиченные правки пользователя. Добавляй в коммит только файлы своей задачи. Сохраняй обе стороны при расхождении веток и избегай принудительной отправки и переписывания опубликованной истории.

## Изменения в аддоне

- Сохраняй совместимость с файлами `.blend`, где камеры уже содержат `Camera.coll_states` с полями `name` и `data`. При изменении JSON предусмотри чтение прежнего формата и проверь открытие файла, сохранённого стабильной версией.
- Согласуй изменения в идентификаторах `cam.*` и панелях, которые их вызывают. Различай активный объект-камеру, `Scene.camera`, активный View Layer и общие флаги объектов и коллекций.
- Регистрируй классы и свойства через `register()` и удаляй их через `unregister()` в обратном порядке зависимостей. Проверяй повторное включение аддона без перезапуска Blender.
- Перед публикацией выполни `git diff --check`, `python -m py_compile Collection_Camera_Manager.py` и затронутые сценарии в отдельной тестовой сцене. Для правок интерфейса проверь обычный пользовательский сценарий в Blender.
- В публичный Git добавляй исходники и документацию. Рабочие сцены, архивы сборок, ключи и локальные конфигурации MCP держи вне репозитория.
